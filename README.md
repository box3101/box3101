# 이찬용 · Frontend Lead & AI Builder

### 작은 불편에서 시작해, 더 나은 경험을 만듭니다.

웹 퍼블리싱으로 시작해 공공 웹사이트와 기업 서비스의 프론트엔드 개발을 담당했습니다.  
지금은 **이즈파크 AX Group의 3인 프론트엔드팀 팀장**으로 일정·업무 배분과 팀 스터디를 진행하며, 공통 UI와 AI 활용 방식을 정리하고 있습니다.

제안서 AI 에이전트에서는 문제 정의부터 기획·UI/UX·프론트엔드 개발까지 맡고,  
개인 프로젝트에서는 백엔드·데이터베이스·배포까지 직접 연결하며 제품을 만드는 범위를 넓혀가고 있습니다.

## 제가 일을 넓혀온 방식

**01 · 누구나 사용할 수 있는 화면을 만드는 일**

공공·기업 웹사이트의 퍼블리싱과 프론트엔드 개발을 맡으며 웹 표준, 접근성, 반응형 UI와 운영을 경험했습니다. 인천광역시 통합 웹사이트 20개 구축·운영에 참여했고, 담당 프로젝트의 웹 접근성 인증 8회 취득과 품질검사 대응을 수행했습니다.

**02 · 팀이 함께 쓸 수 있는 기준을 만드는 일**

반복되는 UI를 공통 컴포넌트로 정리하고, `ispark-ui`를 설계·패키징해 npm으로 배포했습니다. 현재는 3인 팀의 일정·업무 배분과 스터디를 진행하며, AX Group 개발자를 위한 Cursor AI 활용 가이드도 작성했습니다.

**03 · 문제를 정의하고 제품으로 연결하는 일**

제안 업무의 흐름을 분석해 AI 에이전트의 기획·디자인·프론트엔드 개발을 진행하고 있습니다. 개인 프로젝트 TaskFlow에서는 직접 만든 UI 라이브러리를 적용하고, API·DB·배포까지 맡아 하나의 서비스로 연결했습니다.
